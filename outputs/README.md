# OUTPUTS DESCRIPTION

This folder contains the outputs generated from the Interrupted Time Series (ITS) analysis of infant mortality outcomes in Brazil following the implementation of Bolsa Família. It is separeted into folders for figures and for tables.

## Folder structure

### `figures/`

Contains visual outputs produced during the analysis, including:
- initial time series plots
- diagnostic test visualisations
- final ITS regression plots

---

### `tables/`

Contains statistical output tables generated during the analysis, including:
- Breusch-Pagan test results
- Durbin-Watson test results
- final ITS regression output tables
